# Yachay-Tech — Simulador de Toma de Decisiones Académicas

Yachay-Tech es una plataforma gamificada de análisis del comportamiento del consumidor.
El estudiante asume un rol estratégico real, enfrenta una crisis comercial y toma decisiones que tienen consecuencias. 
Aquí no hay respuestas incorrectas, hay decisiones con distintos impactos.

## Funcionalidades del sistema
* Autenticación de usuario
* Gestión de Flujo Dinámico
* Aleatorización de Alternativas
* Checkpoints de Sesión
* Bloqueo de Retrocesos
* Informe Final y Chatbot

## Stack Tecnológico

### Backend
* Java 17
* Spring Boot
* Spring Security (JWT)

### Base de Datos
* MySQL — modelado relacional y flujos dinámicos

### Pruebas de API
* Bruno

### Herramientas
* Trello: gestión ágil (Kanban)
* Git

## Ejecutando la API
* **Modo desarrollo:** La aplicación estará disponible en http://localhost:8080.
* **Documentación de la API:** Puedes probar los endpoints utilizando herramientas como Bruno o Postman.
